# sqb dbt

Orchestrate dbt and SQLBuild together with selection across both project graphs. Ordinary commands compile only the current dbt project and do not fingerprint, freshness-check, prune, or automatically clone dbt models. See [Using SQLBuild with dbt](/concepts/dbt-compatibility/overview) for concepts and selection behavior.

## sqb dbt init

Create or update the SQLBuild companion project for an existing dbt project.

```bash
sqb dbt init --project-dir ../dbt_project --profiles-dir ../profiles
```

## sqb dbt plan

Preview combined dbt and SQLBuild work without executing.

```bash
sqb dbt plan [--select <selector>...] [--exclude <selector>...] [--json] [--verbose]
```

Shows selected and required dbt resources, selected SQLBuild work, and the commands that would be executed.

## sqb dbt run

Run dbt models first, then SQLBuild models.

```bash
sqb dbt run [--select <selector>...] [--exclude <selector>...]
```

## sqb dbt build

Build dbt models first (including dbt tests), then SQLBuild models with audits.

```bash
sqb dbt build [--select <selector>...] [--exclude <selector>...]
```

## sqb dbt test

Run dbt tests first, then SQLBuild unit tests and audits for selected models.

```bash
sqb dbt test [--select <selector>...] [--exclude <selector>...]
```

dbt's `test_type:data` and `test_type:unit` selectors are mapped: `test_type:data` runs SQLBuild audits, `test_type:unit` runs SQLBuild unit tests. Without a test type selector, both run.

```bash
# Run only unit tests
sqb dbt test --select test_type:unit

# Run only unit tests associated with one dbt model
sqb dbt test --select "fact_orders,test_type:unit"
```

SQLBuild resolves the dbt test selection during planning and executes those exact `test` and `unit_test` nodes. Progress and summary totals use the same planned test set.

## sqb dbt clone

Explicitly clone or copy selected production-shaped dbt relations into the active target. `--select` is required.

```bash
sqb dbt clone --select path:models/marts
```

See [Cloning dbt relations](/concepts/dbt-compatibility/clone).

## sqb dbt diff

Compare selected current relations with a configured production ref. Choose one comparison mode.

```bash
sqb dbt diff --select fact_orders --schema-only
sqb dbt diff --select fact_orders --full
sqb dbt diff --select event_time_orders --bounded 30d
```

See [Diffing dbt builds](/concepts/dbt-compatibility/diff).

## Lineage and scenarios

```bash
sqb dbt lineage fact_orders --direction both
sqb dbt scenario test
```

See [dbt column lineage](/concepts/dbt-compatibility/column-lineage) and [dbt scenarios](/concepts/dbt-compatibility/scenarios).

## sqb dbt debug

Run dbt diagnostics followed by SQLBuild diagnostics.

```bash
sqb dbt debug [--no-connection]
```

## Selectors

All `sqb dbt` commands accept `--select` and `--exclude`. Selectors work across both dbt and SQLBuild:

```bash
# SQLBuild model with dbt dependencies
sqb dbt build --select downstream_orders

# Full upstream chain including dbt
sqb dbt build --select +downstream_orders

# Downstream of dbt-native modified models
sqb dbt build --state path/to/state --defer --select state:modified+

# SQLBuild models by tag
sqb dbt build --select tag:nightly

# SQLBuild models by path
sqb dbt build --select path:models/marts

# Exclude by tag
sqb dbt build --select fact_orders+ --exclude tag:nightly
```

See [Selection](/concepts/dbt-compatibility/selection) for full details on how selectors route work between dbt and SQLBuild.

## Configuration

Configure the dbt project location in `sqlbuild_project.toml`:

```toml
[dbt]
project_dir = "../dbt_project"
profiles_dir = "../profiles"
target_path = "../dbt_project/target"
```

See [Project Configuration](/concepts/project-configuration#dbt) for all fields, including `vars` and `production_ref`.

dbt-native `--state`, `--defer`, and `--indirect-selection` options are supported. SQLBuild-native `--defer-to <target>` is available for the SQLBuild portion of `sqb dbt plan/run/build`; it is not supported by `sqb dbt test` and does not clone dbt relations.

`--changes-only`, `[dbt].replay_on_change`, and `[dbt].defer_clone_from` are not supported by dbt interop. Use native dbt state selection or explicit clone/diff instead.
